# Proposal

## Why

先到提交的隊伍不一定有較多作答時間，搶答順位可能讓快慢不同的隊伍失去公平競爭機會。公平模式以各組當下成功題數調整判定時間，提供可由老師控制的補償方式。

## What Changes

- 新增公平模式開關，預設關閉；老師可設定每題延遲秒數，預設 3 秒。
- 公平模式使用實際送出時間加上成功題數乘以延遲秒數，依判定時間排序。
- 教師查看完整公平計算明細，學生端不公開其他組的加權資訊。
- 活動結果標示公平模式是否啟用；新活動重設為關閉及 3 秒預設。

### Modified Capabilities

## Impact

影響 `src/quiz-state.js` 的提交順位計算、`src/server.js` 的教師設定及狀態同步、`public/` 的設定與教師明細，以及相關單元、Socket.IO 和介面測試。沿用既有 `quiz-session` 規格與記憶體活動狀態。
