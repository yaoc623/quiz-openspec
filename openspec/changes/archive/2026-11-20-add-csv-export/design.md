# Design

## Context

See `proposal.md` for motivation and `specs/quiz-session/spec.md` for observable CSV requirements. 活動、題目及提交目前都保存在 `QuizState` 記憶體；有效提交有伺服器收件時間、判定時間、順位與駁回標記。既有 Express 服務使用角色標頭保護教師操作，前端由老師頁面呈現活動控制。

## Goals / Non-Goals

**Goals:**
- 不依賴外部套件，從結束活動狀態產出可下載的 CSV。
- 使用結束後當下的遞補順位與公平模式旗標，並涵蓋每組未作答項目。
- 以可單元測試的純轉換函式隔離格式、時間與跳脫邏輯。

**Non-Goals:**
- 不把 CSV 存在伺服器、不寫入 Google Sheets，也不改變試算表回寫。
- 不支援尚未結束的活動匯出或學生下載。

## Decisions

- **由獨立純函式產生列與 CSV 字串。** 新增 `src/csv-export.js`，輸入活動快照與匯出時間，輸出含表頭的 BOM CSV。相較在 Express 路由或瀏覽器組字串，純函式容易用單元測試覆蓋跳脫和列數，且使用伺服器保存的權威資料。
- **依題目、小題、組別順序展開。** 單題輸出一列但小題號留白；題組每個小題一列。每個組別沒有該小題提交時輸出空白資料列。提交答案列按對應小題索引取值，其提交時間與順位會在題組各小題列重複呈現。
- **狀態依目前提交標記判定。** 未提交為「未作答」；已駁回提交為「已駁回」；目前未駁回且順位第一為「成功」；其餘為「未成功」。搶答順位使用目前有效順位，駁回而未參與有效順位者留空。這不追溯記錄駁回前的舊名次。
- **時間從伺服器毫秒時間戳格式化。** 使用 `Intl.DateTimeFormat` 指定 `Asia/Taipei`，再組合年月日時分秒毫秒；匯出檔名時間也使用相同時區，避免依賴主機時區。無提交的時間欄留空。
- **沿用教師角色驗證的 GET 下載端點。** 在活動結束且使用者角色為老師時才回傳 `text/csv; charset=utf-8`、`Content-Disposition` 下載名稱與 BOM 前綴。老師介面以連結導向該端點；瀏覽器直接下載可避免前端重組資料或複製伺服器權威狀態。
- **套用標準 CSV 欄位跳脫。** 所有含逗號、雙引號、CR 或 LF 的欄位加雙引號，欄位內雙引號加倍；答案換行原樣保留。這比自訂分隔或移除換行更能維持原答案。

## Risks / Trade-offs

- [題目或答案含換行時試算表軟體的顯示方式各異] → 依標準 CSV 保留換行並加入引號，匯入工具可正確解析。
- [執行環境缺少 `Asia/Taipei` 時區資料] → 使用 Node.js `Intl` 的 IANA 時區支援；測試固定驗證台灣時區與毫秒輸出。
- [駁回提交不再有目前有效順位] → 依設計讓駁回列順位留空，狀態欄明確保留「已駁回」。

## Migration Plan

不需資料遷移。部署新程式後重啟 `npm start` 即可；回復時移除下載端點、介面按鈕和 CSV 模組，不影響記憶體以外的資料。
