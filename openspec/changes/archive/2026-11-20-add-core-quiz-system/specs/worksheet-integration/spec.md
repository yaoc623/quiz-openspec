# Spec Delta

## Purpose

讓老師以 Google 試算表作為學習單題目來源，依表格實際內容動態找到題號與答案格，並將搶答成功答案直接寫回原試算表。

## ADDED Requirements

### Requirement: 使用 Sheets API 與安全服務帳號
系統 SHALL 透過 Google Sheets API 直接讀取與寫入雲端試算表，不得下載或轉換為 xlsx；服務帳號憑證 SHALL 存在本機 `credentials.json`、不得寫入程式碼，且 MUST 排除於版本控制之外。介面 MUST 顯示服務帳號 email 與「請先把試算表共用給這個 email（編輯者）」提醒。

#### Scenario: 顯示服務帳號分享提醒
- **GIVEN** 服務帳號憑證可讀取
- **WHEN** 老師開啟試算表匯入介面
- **THEN** 頁面顯示憑證中的服務帳號 email 及編輯者分享提醒

#### Scenario: 忽略本機憑證
- **GIVEN** 專案設定版本控制忽略規則
- **WHEN** 本機放置 `credentials.json`
- **THEN** Git 忽略該檔案且程式碼不含金鑰內容

#### Scenario: 憑證缺失或試算表未授權
- **GIVEN** 憑證不存在、格式錯誤或服務帳號沒有試算表權限
- **WHEN** 老師匯入或回寫試算表
- **THEN** 系統以繁體中文說明問題且不回報匯入或回寫成功

### Requirement: 貼上網址並掃描所有工作表表頭
系統 SHALL 接受老師貼上的 Google 試算表網址，掃描所有工作表，找到同一列同時包含「題號」、「題目」、「作答」的表頭，再依掃描結果定位資料列與欄位。

#### Scenario: 表格任意移位仍可辨識
- **GIVEN** 有效學習單表頭與資料位於任意列及欄
- **WHEN** 老師匯入試算表
- **THEN** 系統依掃描到的表頭列欄正確解析，不依賴固定座標

#### Scenario: 在其他工作表找到表頭
- **GIVEN** 試算表有多個工作表且只有其中一個包含必要表頭
- **WHEN** 老師匯入試算表
- **THEN** 系統掃描全部工作表並匯入含有符合表頭的學習單

#### Scenario: 找不到必要表頭
- **GIVEN** 所有工作表都沒有同列包含三個必要表頭
- **WHEN** 老師匯入試算表
- **THEN** 系統以繁體中文回報格式錯誤且不建立部分題目

### Requirement: 不寫死儲存格座標
系統 SHALL 由表頭掃描結果、列內容及 Sheets API 合併範圍動態推導所有答案目標；程式碼與測試 MUST NOT 依賴固定工作表欄列座標或固定 A1 格址。

#### Scenario: 表格移動後答案位置同步移動
- **GIVEN** 相同學習單表格在另一份假資料中向右及向下移動
- **WHEN** 解析器解析兩份資料
- **THEN** 題目結構相同而答案目標隨表格位置移動

#### Scenario: 回寫使用動態答案目標
- **GIVEN** 解析器已產生各小題的工作表及列欄答案目標
- **WHEN** 系統回寫答案
- **THEN** API 更新位置完全取自解析結果且不使用固定座標

### Requirement: 解析單題及合併題組
系統 SHALL 將表頭以下「題目」欄有文字的列作為小題；題號欄若屬合併範圍，MUST 以該範圍左上角值識別題號。作答欄為半形或全形括號小題標記時，答案位置為作答欄右側一格；否則答案位置為作答欄本身，若作答格合併則使用合併範圍左上角。

#### Scenario: 解析六題單題
- **GIVEN** 假資料學習單含六列有題目文字的單題且作答欄不是括號標記
- **WHEN** 解析器解析學習單
- **THEN** 得到六題、每題一個小題，答案目標為作答欄

#### Scenario: 解析兩個雙小題題組及兩題單題
- **GIVEN** 假資料含第 1、2 題各兩個小題及第 3、4 題各一個小題，題號依合併範圍左上角識別
- **WHEN** 解析器解析學習單
- **THEN** 得到四題，小題數依序為二、二、一、一，且題組答案目標位於作答欄右側

#### Scenario: 支援全形括號並忽略空題目列
- **GIVEN** 作答標記使用半形或全形括號，且資料中含題目欄空白列
- **WHEN** 解析器解析學習單
- **THEN** 兩種括號標記均識別為題組小題且空白列不建立小題

#### Scenario: 單題作答格為合併儲存格
- **GIVEN** 單題作答欄儲存格屬於合併範圍
- **WHEN** 解析器解析學習單
- **THEN** 答案目標為該合併範圍左上角

### Requirement: 僅匯入題號與小題結構
系統 SHALL 使用「題目」欄是否有文字來辨認作答列，但匯入後供搶答畫面使用的資料 MUST 僅包含題號、小題結構及必要答案目標，不得向學生顯示題目文字。

#### Scenario: 匯入不呈現題目文字
- **GIVEN** 學習單題目欄含有題目敘述
- **WHEN** 老師匯入並讓學生進入作答畫面
- **THEN** 顯示題號與所需小題答案欄，不顯示題目敘述

### Requirement: 顯示匯入摘要
系統 SHALL 在成功匯入後顯示題數總數及每題小題數。

#### Scenario: 顯示題目及小題數
- **GIVEN** 學習單已成功解析
- **WHEN** 老師查看匯入摘要
- **THEN** 顯示題數總數與逐題小題數

### Requirement: 回寫搶答成功組答案
系統 SHALL 在活動結束後將每題第一順位組別的完整答案寫入解析出的原試算表答案格，並保留其他未指定儲存格內容。

#### Scenario: 回寫單題與題組
- **GIVEN** 活動已結束且題目有成功組別答案
- **WHEN** 老師執行回寫
- **THEN** 單題及題組答案分別寫入解析出的答案格，其他格不變

#### Scenario: 回寫失敗
- **GIVEN** Google Sheets API 拒絕寫入或回報錯誤
- **WHEN** 老師執行回寫
- **THEN** 系統明確顯示未完成且不回報成功
