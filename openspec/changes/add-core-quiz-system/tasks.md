# Tasks

## 1. Node.js 執行基礎

- [ ] 1.1 建立 `package.json`、Express/Socket.IO/googleapis 依賴及啟動入口；執行 `npm start` 並確認服務監聽 `localhost:3000`。
- [ ] 1.2 加入 `credentials.json` 忽略規則；以 `git check-ignore credentials.json` 確認命中，並檢查程式碼無憑證內容。
- [ ] 1.3 建立繁體中文首頁骨架；執行 `npm start` 並確認首頁可載入。

## 2. 學習單解析器

- [ ] 2.1 實作掃描所有工作表、尋找同列三個必要表頭並回傳動態索引；以表頭位移假資料執行 `node --test` 確認解析正確。
- [ ] 2.2 實作合併題號的左上角讀取及六題單題解析；以六題假資料執行 `node --test` 確認題數為六且每題一小題。
- [ ] 2.3 實作半形/全形括號題組辨識與作答欄右側答案目標；以第 1、2 題各兩小題、第 3、4 題單題的合併格假資料執行 `node --test` 確認題數及小題數依序為 2、2、1、1。
- [ ] 2.4 實作忽略題目欄空白列及單題作答合併格左上角定位；以包含空白列及作答合併格的假資料執行 `node --test` 確認不多建題且答案目標正確。
- [ ] 2.5 加入表格向右、向下移動的解析測試；執行 `node --test` 確認題目結構不變、答案索引隨表格移動，且程式與假資料未依賴固定 A1 座標。

## 3. Google Sheets 讀寫

- [ ] 3.1 實作試算表網址解析及透過 Sheets API 讀取所有工作表 values/merges；以 mock API 測試多工作表尋找表頭，執行 `node --test` 確認不需下載 xlsx 或連線真實 Google。
- [ ] 3.2 實作服務帳號憑證載入與 email 顯示/分享提醒；以假憑證測試 email，並以缺失/格式錯誤憑證測試繁體中文錯誤，執行 `node --test` 和 `npm start` 確認服務仍可啟動。
- [ ] 3.3 實作無表頭/無權限時拒絕部分匯入；以 mock API 測試失敗不建立題目，執行 `node --test` 確認通過。
- [ ] 3.4 實作依解析索引產生 Sheets API 寫入目標並批次回寫成功組答案；以 mock API 驗證單題、題組、其他格不變及 API 錯誤，執行 `node --test` 和 `npm start` 確認通過。
- [ ] 3.5 加入憑證不進版控的自動檢查；建立測試用憑證路徑並執行 `git check-ignore` 確認被忽略，執行 `npm start` 確認忽略設定不影響啟動。

## 4. 搶答服務

- [ ] 4.1 實作預設四組、老師設定正整數組數與準備中狀態；以 `node --test` 測試預設值、有效設定和無效設定，並執行 `npm start` 確認服務可啟動。
- [ ] 4.2 實作開始/結束階段轉換及新連線取得目前階段；以 `node --test` 測試三階段合法與非法轉換，並執行 `npm start` 確認服務可啟動。
- [ ] 4.3 實作只在搶答中接受答案、同組同題一次及題組欄位完整性；以 `node --test` 測試階段外、重複及不完整提交，並執行 `npm start` 確認服務可啟動。
- [ ] 4.4 實作伺服器收件時間與順位；以 `node --test` 驗證多組有效提交的順位及無效提交不搶順位，並執行 `npm start` 確認服務可啟動。
- [ ] 4.5 實作教師/學生 Socket.IO 資料分流；以 `node --test` 驗證老師可見所有答案、搶答中學生的狀態與推送不含他組答案，並執行 `npm start` 確認服務可啟動。
- [ ] 4.6 實作結束後結果資料；以 `node --test` 驗證老師及學生可查看每題成功組別與完整答案，並執行 `npm start` 確認服務可啟動。

## 5. 前端流程與整合

- [ ] 5.1 完成角色/組別選擇、組數設定、試算表網址匯入及題數摘要；執行 `npm start` 並以瀏覽器確認匯入流程不顯示題目文字。
- [ ] 5.2 完成老師搶答控制及即時作答列表；執行 `npm start` 並以老師與多組學生瀏覽器確認階段同步、組別/答案/時間/順位顯示。
- [ ] 5.3 完成學生搶答中個人組別作答介面與結束後結果畫面；執行 `npm start` 並以不同組別瀏覽器確認作答前後的資料隔離及結束後結果可見。
- [ ] 5.4 完成老師結束後回寫按鈕及成功/失敗提示；以 mock Sheets API 執行端到端測試，再執行 `npm start` 確認回寫流程可用。
- [ ] 5.5 執行整體驗收：執行 `node --test` 及 `npm start`，以老師和至少兩組學生完成匯入、搶答、結束、檢視結果與回寫流程。
