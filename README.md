# 課堂搶答系統

以 Node.js、Express、Socket.IO 和 Google Sheets API 建立的本機課堂搶答系統。學號保存在 `.quiz-data/students.json`，活動、組別、題目截止時間、已受理佇列、作答、審核及揭曉狀態保存在 `.quiz-data/activity.json`。重啟後重新登入可恢復本輪，停機時已到期的題目會關閉。

## Windows 安裝與啟動

使用 Node.js 22 或更新的 LTS 版本與 Git。在 Windows 開啟「命令提示字元（CMD）」，執行：

```cmd
cd /d C:\quiz-openspec
npm ci
copy .env.example .env
notepad .env
```

在記事本填入 `TEACHER_USERNAME` 與 `TEACHER_PASSWORD`，例如保留帳號 `teacher`，在密碼的等號後填入你自行設定的強密碼。存檔後在原本視窗執行：

```cmd
npm start
```

開啟 <http://localhost:3000>。按 Ctrl+C 停止。變更帳密後請重新啟動，`.env` 由 Git 忽略。兩個欄位皆須設定才能登入教師控制台。`PORT=3000` 可調整本機連接埠。教師連續失敗 5 次後，同一來源須等待該分鐘的限制解除。登入 Session 有效 12 小時，登出或重啟後需重新登入。如果使用 PowerShell ，請用 `npm.cmd ci` 和 `npm.cmd start`。

## 設定 Google 服務帳號

1. 在 Google Cloud 專案啟用 Google Sheets API，建立服務帳號並下載 JSON 金鑰。
2. 將下載的檔案放到專案根目錄，檔名為 `credentials.json`。此檔已列入 `.gitignore`，不要提交或貼到程式碼中。
3. 啟動網站後，老師畫面會顯示服務帳號 email；也可從憑證 JSON 的 `client_email` 欄位取得。
4. 在 Google 試算表右上角按「共用」，將試算表共用給該 email，權限設為「編輯者」。
5. 在老師畫面貼上試算表網址並按「掃描匯入」。系統會掃描所有工作表，尋找同列包含「題號」、「題目」、「作答」的表頭。資料位置依掃描結果與合併儲存格計算。

若尚未放入憑證，網站仍可啟動；匯入或回寫時會顯示繁體中文錯誤。單元測試使用假資料和 mock API，不需要真實憑證或 Google 連線。

## 教師與學生操作

1. 瀏覽首頁，展開「教師登入」，輸入設定的帳密。設定組數、掃描匯入試算表、套用倒數與公平模式。
2. 用另一個瀏覽器或獨立瀏覽器設定檔登入學生。輸入數字學號，第一次進入本輪時選組並再按「學生登入」。教師可在學生首次作答前從控制台調組。已有組別的學號再次登入會自動沿用。
3. 教師點題號旁的「開始搶答」或「停止搶答」。每題獨立計時與開關。同組每位學生皆可各答一次。也可使用底下的全題與依序逐題搶答。學生等題目開放後，填完所有答案再按「搶答！」，按下後先鎖定並顯示「傳送中」，收到後端收件回覆顯示「已送出」或「已截止」。收件未獲確認時會用原內容重送，背景驗證未通過會保留鎖定並顯示原因。
4. 教師查看所有有效提交、順位並審核，結算後學生可看已公布的第一名。結算預設遮蔽結果。教師可點指定題號公布、用投影依序揭曉，或一次公布全部。
5. 教師完成審核後，下載每筆回答一列的 UTF-8 BOM CSV，題組答案以 JSON 陣列保留，疑似公式的內容加上文字前綴，或按「回寫成功答案」。回填使用批次寫入，暫時性錯誤會自動退避重試最多三次。若回填後又修改審核，請重新回填有勝者的題目，已無勝者的舊填入值須在試算表上人工清理。需要在 Excel 保留學號前導零時，請使用「資料 → 從文字/CSV」，將學號欄型別設為文字。
6. 教師可開始新活動，下一輪重新分組，既有帳號會保留。學生可登出再登入本輪，以相同學號恢復組別、已送出答案與可見結果。未送出的草稿依活動、學號、題目保存在當分頁的 Session Storage。

判定先依伺服器收件時間加固定延遲排序，相同判定時間以收件流水號決勝。公平模式延遲為該組收件當下已確定的勝題數乘上每題延遲秒數。開放中的暫定第一名不計入分數或公平延遲，關題並清完受理佇列後才確定第一名。

學號登入是課堂用簡易身分識別。知道學號的人可能冒用，請使用虛構學號進行展示。Cookie 為同一瀏覽器設定檔內的分頁共用，教師及各學生示範應使用不同設定檔。服務只監聽本機 `127.0.0.1`，實體裝置須能連到同一服務才可共用帳號，本專案的 localhost 設定只供同一台主機操作。

### 設定 10 秒並逐題搶答

匯入至少兩題，在「搶答時間」選「自訂秒數」並輸入 `10`，勾選「逐題搶答」，再按「開始搶答」。開始時會直接套用畫面時限。歸零或按「關閉本題」後，可按「開始下一題」取得新的 10 秒。最後一題關閉時會結束整場活動。計時自動結束時結果仍遮蔽，教師可逐題揭曉或按「公布全部結果」。逐題選項未勾選時，所有題目共用同一個活動倒數。

## 測試

```sh
npm test
npm run test:stress
```

執行 `openspec validate student-login-and-ta-compliance --strict` 和 `openspec validate --specs --strict` 可驗證規格。

測試涵蓋學號持久化、Cookie 權限、跨連線作答、獨立期限、表頭與資料位移、單題和題組解析、模擬 Google Sheets 讀寫、草稿、回填競態、加分功能及教師與兩組學生的即時流程。測試會使用本機迴路連線，無須 Google 憑證。實際雲端讀寫須使用具編輯權限的服務帳號。
