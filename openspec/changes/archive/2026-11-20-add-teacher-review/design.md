# Design

## Context

`QuizState` 已保存每題提交及排名，公平模式使用送出時保存的判定時間。伺服器以角色專用快照推送狀態，試算表回寫直接選取順位第一筆答案。

## Goals / Non-Goals

**Goals:** 以可逆的駁回標記調整有效順位，並讓即時結果、排行榜、公平計分與雲端回寫使用同一結果來源。

**Non-Goals:** 不刪除提交歷史、不改寫既有送出時間或公平判定時間、不增加教師審核工作流程以外的權限系統。

## Decisions

- 每筆提交保存 `rejected` 布林值，預設為 `false`；駁回和取消駁回只允許教師透過伺服器端 API 操作。
- 同題只對目前順位第一且未駁回答案執行「駁回」；駁回後依原排序規則對未駁回答案重新排順位，被駁回資料保留並顯示「已駁回」。公平模式使用原判定時間，關閉時使用伺服器收件序號。
- 「取消駁回」只接受已駁回答案，清除標記並重新計算順位。操作可在搶答中或已結束後執行。
- 重算後若無有效提交，公開結果代表無人答對；試算表回寫跳過該題。排行榜只統計有效順位第一答案。
- 公平模式新提交的成功題數從目前有效順位第一答案計算，因此駁回會影響之後提交的公平權重；既有提交的權重與判定時間維持原值。

## Risks / Trade-offs

- 駁回會改變既有排行榜及之後公平權重，因此每筆原始提交與駁回狀態都保留，以利教師檢視及取消。
- 若所有答案均遭駁回，該題不會寫入試算表；其它題仍按有效答案回寫。
